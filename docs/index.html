cwi-milestone-wire

A milestone-detection sensor for Cumulative Web Inc. It watches verified data sources — playlist placements and stream counts — and emits a structured alert payload when a real milestone fires. Zero dependencies, Node stdlib only, $0.

Placements verified before arming never fire — only new verified events do. Per the no-zeros law, this page stays silent until the sensor fires on something verified.

Evidence tiers

Every alert carries its evidence tier and verification link. Only these fire:

TierMeaningFires?
SILVERDistributor / label dashboard (screenshot)Yes
BRONZEPublic third-party API (e.g. Spotify/Deezer)Yes
REPORTEDDated, attributed manager/team statementYes
SAMPLEDemonstration fixture — fictitiousOnly in --demo, stamped
PROJECTEDForecast — never an achievementNever

What fires a milestone

  • Stream crossing: a new verified figure above the last verified figure that crosses a threshold (Zooted Zone ROAD-1M: 500K / 750K / 1M; Diabolique, Shaka Zulu, Doves & Diamonds: 50K / 100K / 250K).
  • New verified placement: a track appears on a playlist it was not known to be on, verified by scan.
  • Position jump ≥ 5 on a tracked playlist.
  • Reaching #1 on any tracked playlist.

Alert payload

Each alert is JSON with track, milestone, detail, evidence tier, verified date, verification method, receipt link, baseline, and draft promo copy for Threads / Instagram / WhatsApp (all labeled [DRAFT]; CWI accounts may fire per standing order — Black's personal name, DMs, emails, subscriber blasts, and personal Facebook stay gated).

{
  "wire": "cwi-milestone-wire",
  "version": "1.0.0",
  "track": "Zooted Zone",
  "milestone": "stream_crossing",
  "detail": "500,000 lifetime Spotify plays",
  "evidence_tier": "SILVER",
  "verified_date": "2026-09-19",
  "verification": "DistroKid dashboard screenshot",
  "receipt_link": "...",
  "copy": { "threads": "[DRAFT — CWI account only] ...", "...": "..." }
}

Kill rule

Event-driven: no verified milestone in 120 days from arming (2026-09-19) → PARK the lane (not kill). A parked lane keeps the sensor runnable but stops scheduled checks.
